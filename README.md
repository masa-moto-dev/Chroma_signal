# CHROMA SIGNAL

特定の色（最大3色）だけを残し、それ以外をグレースケールにするブラウザ完結型の画像加工Webアプリです。
バックエンド不要で、GitHub Pagesでそのまま使用できます。

## ローカルで起動
ローカルで起動する場合は適当にクローンした後で、以下の手順を使うと使用できます。

ES Modulesを使うため、`index.html`の直接起動ではなく簡易HTTPサーバーを利用します。

```bash
cd color_accent_app
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。


## 主な機能

- 最大3色を独立したΔE76しきい値で保持
- キャンバスクリック時に周辺5×5の平均色を取得
- ブラウザ標準カラーピッカーとRGB数値入力
- 色スロットごとの「画像全体／指定領域のみ」切り替え
- スロットごとに複数の矩形領域を追加・削除
- 操作中800px、確定1600px、保存時は長辺最大4096px
- 色フェザー、Rec.709によるグレースケール変換
- 左下のカラーシグネチャ（選択色＋HEX）
- 右下の `ACCENTED WITH / CHROMA SIGNAL` ブランド署名
- 各署名の表示／非表示
- PNG出力

## ファイル構成

- `index.html` — UI
- `css/style.css` — スタイル
- `js/main.js` — イベントと状態管理
- `js/imageLoader.js` — 読み込み・リサイズ
- `js/colorPicker.js` — 色取得とスロット管理
- `js/colorSpace.js` — RGB→Lab・ΔE76・輝度
- `js/regionSelection.js` — 矩形領域の操作と表示
- `js/effect.js` — 選択色・領域判定とグレー化
- `js/signature.js` — カラー／ブランド署名
- `js/exporter.js` — 原寸PNG出力

## 現時点の制限

- 矩形の移動・リサイズは未対応です。削除して描き直す必要があります。
- 領域境界のフェザーは未対応です。
- 大きな画像の書き出しはメインスレッドで処理するため、一時的に画面が止まる場合があります。
- EXIF回転、アプリ独自のズーム／パンは未対応です。
